# Congenital Heart Disease Interactive Lab

A self-contained, offline-first cardiology study website rebuilt from the supplied congenital heart disease chapter and modeled on the supplied Rheumatic Fever Interactive Lab.

## Open the website

1. Extract the ZIP archive.
2. Keep all files together in the same folder.
3. Open `index.html` in a modern browser.

No installation, server, account, or internet connection is required for the core website.

## Included learning tools

- 29 interconnected topic modules with sidebar navigation
- Physiology-first lesion classification and shunt reasoning
- Detailed ASD, VSD, PDA, pulmonary stenosis, coarctation, TOF, d-TGA, Eisenmenger, and related-lesion modules
- Interactive shunt, murmur, diagnostic, and arm–leg pressure explorers
- Hypercyanotic-spell emergency sequence
- 10 progressive clinical cases
- 50 sectioned flashcards
- 24-question quiz with explanations and score tracking
- Search, bookmarks, visited-module progress, focus mode, timer, and private local notes
- Light/dark themes
- Section-level browser text-to-speech with pause/resume support
- Embedded source PDF for reference

## Files

- `index.html` — application entry point
- `styles.css` / `upgrades.css` — responsive visual system and study-tool styling
- `content.js` — structured chapter modules, cases, flashcards, and quiz content
- `app.js` / `upgrades.js` — navigation, interactivity, search, TTS, progress, and study tools
- `congenital-heart-disease-source.pdf` — supplied source chapter

## Notes

Progress, bookmarks, theme choice, and notes are stored only in the browser's local storage. Clearing site data resets them. The website is an educational revision aid and does not replace lesion-specific assessment or local clinical protocols.
